# ETHAN VIBE

**Create. Connect. Compete. Earn.**

ETHAN VIBE is the social and creator community platform in the Ethan Digital ecosystem.

## Product scope
- Social feed with text, image, and short-video posts
- Creator profiles, follows, likes, and comments
- Direct messaging and notifications
- Communities, challenges, creator competitions, points, and leaderboards
- Responsive installable Progressive Web App

## Infrastructure
- PostgreSQL on Neon
- API service hosted on Railway
- Media storage provider to be configured before enabling uploads

## Repository status
Application scaffolding is being established. Do not treat the platform as production-ready until authentication, authorization, media storage, moderation, and deployment checks are complete.
